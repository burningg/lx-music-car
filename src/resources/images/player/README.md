# Player icons

Phosphor Icons (regular weight): `shuffle`, `repeat`, `queue`, `corners-out`.
Source: https://github.com/phosphor-icons/core/tree/main/assets/regular
License: MIT (see `LICENSE`).

The source SVGs are kept in `design/icons/svg/ph-*.svg`. These transparent
128×128 PNGs are rasterized with `sharp` and tinted at runtime to match Pen's
night/day colors. They require no SVG renderer or new runtime dependency.

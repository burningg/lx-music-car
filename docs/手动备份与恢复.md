# 手动备份与恢复

入口：**设置 → 备份与恢复 → 应用备份（设置、音源与歌单）**。
本功能只在点击按钮时工作，不自动备份，也不上传数据。

## 卸载前备份

1. 点击 **导出备份**，选择 `Download`、`Documents` 或外置存储上的公共目录。
2. 导出成功后会显示文件位置，文件名为 `lx-music-car-backup-<时间>.lxmc`。
3. 用文件管理器确认文件存在，建议另存一份到 U 盘或电脑，再卸载应用。

不要保存到应用私有目录或 `Android/data`，这些位置会随卸载被删除。
应用会拒绝可识别的私有目录，但第三方文档提供器的存储位置可能不透明，仍需自行确认。
备份经过压缩，**没有加密**；音源脚本可能含有密钥、地址等私密信息，不要公开分享。

## 重装后恢复

1. 重新安装后，进入同一入口，点击 **恢复备份**。
2. 授权文件访问并选择之前导出的应用备份。
3. 核对备份时间、音源和歌单数量，确认覆盖当前数据。建议先导出当前数据。
4. 应用关闭后，手动重新打开；启动时完成恢复并显示结果。

恢复是**替换**，不是合并。包含音源脚本的备份会在重新启动时加载脚本，只恢复自己信任的文件。
恢复时会关闭数据同步，避免旧同步连接立即覆盖恢复结果；如需同步，请手动重新连接。
系统文件访问、悬浮窗等权限不能通过备份授予，应按系统提示重新授权。

## 备份范围

| 包含 | 不包含 |
| --- | --- |
| 应用设置、字号、主题配置 | 音乐文件、主题背景图片 |
| 自定义音源信息和完整脚本、当前音源选择 | 音乐与歌词缓存 |
| 试听列表、收藏、全部用户歌单及歌曲信息 | 临时播放队列、播放进度、历史记录 |
| 不喜欢规则 | 同步授权、系统权限、文件夹授权 |

本地歌曲只保存歌曲信息和文件路径，不打包音频。换设备后需要自行复制文件、保证路径可用。
主题配色配置会备份，但自定义背景图片需要另外保存。
恢复不会导入其他设备的用户协议同意状态。

## 文件兼容与故障处理

- 应用备份使用独立的 `lx-music-car-backup` 类型和格式版本号，不能当成桌面版配置或普通歌单备份使用。
- 原有 **列表数据 → 导入列表 / 导出列表** 功能保留，用于与桌面版交换歌单。
- 不完整、损坏或不支持的备份在覆盖数据前会被拒绝。导出失败不会显示成功。
- 已确认的备份先暂存在应用私有目录，直到下次启动才写入设置；此时不要再次卸载或清除数据。
- 启动恢复前会短暂保存一份用于失败回滚的内部事务记录；恢复完成即删除。这不是自动备份功能，也不能跨卸载保留。
- 恢复失败或进程中断时，会优先还原恢复前的数据。若设备存储故障导致回滚也无法完成，应用停止初始化，避免继续使用半恢复的数据；释放空间后重新打开以重试回滚。

如果已经卸载且未导出备份，无法通过此功能找回原配置。普通升级应使用相同包名、相同签名的 APK 覆盖安装，不必卸载。
